# 🚀 ProDesk Onboarding Wizard

A modern, responsive **Multi-Step Employee Onboarding Wizard** built with **React.js + Vite**. The application guides users through a structured registration process using React Hook Form, Zod validation, animated progress tracking, dark mode, and persistent local storage.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/prodesk-onboarding.git
```

Go to the project folder

```bash
cd prodesk-onboarding
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

---

# 📦 Build for Production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
